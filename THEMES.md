# Theme Catalog

This file records the visual theme ideas

## 1\. Midnight Nimbus

- Description: Dark, moody palette with deep blues and smoky grays.
- Design considerations:

  - Color: deep blues, charcoal, smoky gray accents
  - Typography: crisp sans-serif
  - Card styling: glassmorphic cards with soft glow edges
  - Layout density: medium density with generous spacing
